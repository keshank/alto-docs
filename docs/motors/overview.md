# Motors overview

Alto Motors manufactures two main motor families:

## BLDC motors

Brushless DC motors for precise speed control applications.

- **AL57 series** — 24–48 V, up to 750 W, 4000 RPM max
- **AL86 series** — 24–72 V, up to 3 kW, 3000 RPM max

[View AL57 documentation →](/docs/motors/bldc-al57)

---

## Induction motors

Standard IEC frame three-phase and single-phase AC induction motors.

- **IEC 63–90** — 0.18 kW to 1.5 kW
- **IEC 100–132** — 2.2 kW to 7.5 kW

[View induction motor documentation →](/docs/motors/induction)
